\[\xi(s) = \xi(0) \prod_{n=1}^{\infty} \left( 1 - \frac{s}{\rho_n} \right)\]

\[\frac{\xi'(s)}{\xi(s)} = \sum_{n=1}^{\infty} \frac{1}{s - \rho_n}\]
